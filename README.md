# 산사의 고요

브라우저에서 바로 즐기는 3D 명상 게임입니다. 설치 없이 `index.html`을 열면 됩니다.

## 장면

- **호숫가 명상** — 해와 달의 크기에 맞춰 호흡하면 호수에 연꽃이 핍니다. 싱잉볼 소리를 켜고 끌 수 있고, 소원 연등을 물 위에 띄울 수 있습니다. 명상은 혼자 하는 공간입니다.
- **숲속 모닥불(불멍)** — 장작 넣기, 불씨 뒤적이기, 마시멜로 굽기, 불꽃놀이, 오로라 불씨, 소원지 태우기. 통나무 의자에 앉아 불을 바라볼 수 있습니다. 1인칭과 3인칭 시점을 오갈 수 있습니다.
- **눈 내리는 노천온천** — 김이 피어오르는 바위 온천에 걸어 들어가 몸을 담급니다. 대나무 물대롱에서 흐르는 물소리, 석등, 눈 내리기를 켜고 끌 수 있습니다.
- **노을 바다 선상낚시** — 작은 배에서 낚싯대를 던지고, 입질이 오면 챔질한 뒤 줄 긴장을 보며 감아 올립니다. 고등어·전갱이·볼락·우럭·참돔 등 9종(가끔 낡은 장화)이 잡히고, 갈매기가 날아와 뱃머리에 앉았다 갑니다.
- **산사 법당** — 방석 15개가 깔린 법당. 큰절·반배·앉기를 누르면 빈 방석을 찾아가 그 위에서 절합니다. 스님 염불·목탁 배경음, 108알 염주, 소원 연등 달기.

법당·모닥불·온천에서는 바닥을 누르거나 방향키·WASD로 걸어 다닐 수 있습니다.

## 함께하기

- **claude.ai 아티팩트**로 열면 claude.ai의 실시간 기능으로 함께합니다(로그인 필요).
- **GitHub Pages 등 일반 웹**에서는 [Supabase Realtime](https://supabase.com/docs/guides/realtime/presence)으로 로그인 없이 누구나 함께할 수 있습니다. `index.html` 안의 `window.SANSA_RT`에 Supabase 프로젝트 URL과 publishable(anon) 키를 넣으면 켜지고, 비어 있으면 혼자 즐기는 화면으로 동작합니다.
- 법당·모닥불·온천·바다에서 함께할 수 있고, 호숫가 명상은 혼자만의 공간입니다. 입장할 때마다 '맑은 연꽃 42' 같은 이름이 무작위로 주어집니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 게임 전체 (three.js r128을 cdnjs에서 불러옴) |
| `buddha.jpg` | 법당 후불탱화·불상 이미지 |
| `ymbul-loop.webm` | 법당 염불·목탁 녹음 (10분, 끊김 없이 반복) |
| `onsen-loop.webm` | 온천 물소리 배경음 (약 1분, 끊김 없이 반복) |

소리는 첫 클릭 뒤에 재생됩니다. 기록(절 횟수, 명상 시간, 소원 등)은 각자의 브라우저에만 저장됩니다.

## GitHub Pages로 공개하기

저장소 **Settings → Pages**에서 브랜치를 `main`, 폴더를 `/ (root)`로 지정하면 `https://<계정>.github.io/<저장소>/`에서 바로 열 수 있습니다.
